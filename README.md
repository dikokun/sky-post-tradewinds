**Sky Post: Tradewinds** — an original 3D flight game about a courier pilot in the Kaldera Reach, a drowned volcanic archipelago of eight islands where flying is the only way anything moves. Fly thirteen contracts (cargo, passengers, med-evacs, ring courses, supply drops, photo recon over an active volcano, a grand tour of all eight islands — and an intercept: sky raiders tax the mail routes, and a hangar-bought wing gun pod lets you splash them for a bounty) across three unlockable aircraft, with a real flight model (lift, stalls, coordinated turns, ground effect), fuel and airframe damage that turn every sortie into decisions, five named weather conditions including ash that eats engines, a working cockpit instrument panel, and a career of credits, ranks, upgrades and medals that persists between sessions. Everything is procedural — terrain, aircraft, sound — and the game runs offline from static files (three.js vendored).

## Run it

```sh
node serve.ts   # then open http://localhost:8080
```
